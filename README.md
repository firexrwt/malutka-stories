# МАЛЮТКИ: ЭТОГО НЕ БЫЛО В ПОВЕСТКЕ

**Процедурный пиздец в одной комнате. Теперь с нейронкой и кнопкой «продолжить».**

Совет директоров собирался обсудить важные вопросы. Через три минуты Арбуз уже требует кресло, Принц приватизировал микрофон, а Файрекс пытается понять, кто опять выдернул кабель.

Ты пишешь, что происходит. Малютки отвечают. Нейронка двигает персонажей, меняет рожи, выбирает фон и делает вид, что происходящее ещё можно назвать собранием.

Ни один корпоративный процесс не пережил эту демку.

![Переговорная, в которой скоро перестанут переговариваться](public/games/stories/assets/background-meeting-v1.webp)

## Что это за хрень

Локальный браузерный чат с визуальной сценой. Три завязки, дальше пишешь ты:

- **Пять минут до стрима.** Микрофон умер. Принц считает, что техника боится его статуса.
- **Арбуза не звали.** Арбуз пришёл. Повестка больше не ваша.
- **Совет директоров.** Принц принёс поправку, по которой Принцу достаётся Принц, Принц и ещё немного Принца.

Это начало разговора, а не три заготовленных рассказа. Можно чинить микрофон, ругаться, уйти в коридор или внезапно устроить допрос стула. История продолжает написанное, без отдельного судьи сюжета и квестового «сначала возьми кабель, потом получи справку».

Пихта - парень. Арбуз - без ног. Совет - без контроля над ситуацией.

## Запустить этот позор

Нужен **Node.js 22+**. Для настоящих ответов нужен вход в ChatGPT и разрешение использовать лимиты своей подписки. Доступные модели берутся из твоего аккаунта.

Скачай репозиторий через **Code -> Download ZIP** и распакуй. Или:

```sh
git clone https://github.com/firexrwt/malutka-stories.git
cd malutka-stories
npm start
```

Открой [локальную демку](http://127.0.0.1:3116/games/stories/), нажми **Continue with ChatGPT**, разреши запросы по подписке, выбери модель и неприятность. Оставь терминал включённым. Если закрыть сервер, Малютки не научатся отвечать по голубиной почте.

`npm install` не нужен: внешних пакетов нет. API-ключ, Python, CUDA и двадцать гигабайт весов тоже не нужны. Картинки уже лежат в репозитории; во время разговора модель выбирает готовые портреты и фоны.

Сервер слушает только `127.0.0.1`. Это приложение на компьютере игрока. Ссылка с телефона не телепортирует туда сервер с компьютера. Проверено на macOS; живой запуск на других ОС пока не проверен. Хранилище использует права файлов владельца, поэтому обычный Windows-запуск пока не заявлен.

## Как написать хуйню правильно

Речь пиши обычным текстом. Действия - в одиночных звёздочках:

```text
Да господи, просто подрубите резервный микрофон.
*Подключил новый микрофон и тестирую звук*
Во, всё, норм работает.
```

Никаких заклинаний из списка команд. Что написал, то и продолжает рассказчик.

Кликни на героя в кадре или выбери его над полем ввода, чтобы писать от его лица. Ответы подписаны именами. Через **Добавить персонажа** можно позвать готового героя, придумать своего или отдать эту сомнительную кадровую задачу рандому.

Новый персонаж получает отдельное имя и характер, а внешность подбирается из готового банка. Уместный мат есть. NSFW в замысел не входит.

## Хочу сначала без входа

```sh
npm run stories:test
```

Это **тестовые фикстуры, не нейронка**. Подходит посмотреть интерфейс, роли и арты. Два сервера на одном порту не живут: останови предыдущий через Ctrl+C.

## Где лежит компромат

Локальные сессии и данные входа сохраняются в `.local/stories/chatgpt/`. Тестовые истории живут отдельно в `.local/stories/test/`. Эти каталоги исключены из Git.

Приложение обращается к OpenAI при входе и генерации. Репозиторий не содержит аккаунтов, токенов или чьих-либо прошлых переписок. Кнопка **ВЫЙТИ** очищает локальную историю и вход этой сессии.

## Для тех, кто решил это чинить

```sh
npm test
```

Vanilla JavaScript в браузере, Node.js на сервере, готовые WebP. Один обычный ход - один запрос рассказчику. Он получает предыдущий разговор, память и выбранного автора, а возвращает реплики и постановку сцены. История сохраняется после успешного ответа и продолжается дальше.
